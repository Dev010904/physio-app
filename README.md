# Physio App (working name)

Offline-first physiotherapy home exercise app with on-device AI.
Spec and roadmap: <https://claude.ai/code/artifact/4a4808d3-cfb5-4e04-bd01-da28f109b313>

## Run it

1. Copy `env/example.json` to `env/dev.json` and fill in the values you have.
   Every value is optional; the app runs offline without them.
2. Plug in an Android phone with USB debugging on, then:

```bash
flutter run --dart-define-from-file=env/dev.json
```

Build an installable APK instead:

```bash
flutter build apk --debug --dart-define-from-file=env/dev.json
```

## Layout

| Path | What lives there |
| --- | --- |
| `lib/main.dart` | Start-up: optional Supabase and Sentry, bundled exercise library, then the app |
| `lib/app.dart` | App shell and the "About this build" status screen |
| `lib/config/env.dart` | Build-time settings read from `env/*.json` |
| `lib/home/` | Today screen with the current program |
| `lib/exercises/` | Exercise model, library loader, library and exercise pages |
| `lib/session/` | Session plan (all timers come from the prescription), controller, cues and player |
| `assets/exercises/` | Starter exercises and demo program (draft until a physiotherapist reviews them) |
| `assets/sounds/` | Cue tones, generated by `dart run tool/gen_tones.dart` |
| `supabase/migrations/` | Database schema with row-level security |

## Test

```bash
flutter test
```

`test/session_plan_test.dart` pins the timer maths, including the "3 reps with a 30 s hold"
case that other apps get wrong.

## Services

- **Crash reporting:** Sentry project `dev-u15/physio-app`. The app sends no personal data or screenshots.
  In Sentry, turn on *Project Settings → Security & Privacy → Prevent Storing of IP Addresses*,
  otherwise Sentry derives a city from the network address.
- **Backend:** Supabase project `physio-app` (ref `htbvpkxhbftbqbicmmgp`), Mumbai (ap-south-1).
  Both files in `supabase/migrations/` are applied. Row-level security was tested with
  clinicians and patients from two clinics, and the security advisor reports no issues.
